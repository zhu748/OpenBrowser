## 本轮补充修复

| 问题 | 修复 |
| --- | --- |
| 安装器扩展路径在全部平台转小写 | 提取 extension-identity.js，使安装与同步共用路径比较；POSIX 区分大小写，Windows 保持大小写兼容 |
| 安装器 JSON null 帧抛错 | 非对象帧不再访问 id，不中断正常命令 |
| 序列化失败仍留下待处理条目与计时器 | 在注册命令之前构造帧，失败立即拒绝；同步写入错误也结算所有待处理命令 |
| 管道 EOF/close 后继续接受命令 | 明确记录关闭状态及首个错误，清理缓冲和计时器，后续请求立即失败 |
| Browser.close 先退出、后注册 exit 监听 | 发送前注册监听；已经退出立即返回，关闭响应丢失时由进程退出结算；超时后移除监听并终止存活进程 |
| 安装器关闭期限可被命令超时与退出等待叠加 | 一次 5 秒退出等待覆盖关闭流程，不再串行等待两套超时 |

新增 extensionpipe 回归覆盖真实生产入口的序列化、错误帧、EOF、同步写入失败、已退出进程、同步退出事件、无响应但已退出、超时清理，以及实际平台的路径协调。
